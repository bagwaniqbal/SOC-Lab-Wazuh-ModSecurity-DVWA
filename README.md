# SOC Lab Environment using Wazuh, ModSecurity & DVWA

## Overview
This repository contains a documented SOC lab project implemented in a training environment using open-source security tools. The project demonstrates how a Web Application Firewall (ModSecurity with OWASP CRS) and a SIEM platform (Wazuh) work together to detect, block, and analyze common web-based attacks.

## Tools & Technologies
- Wazuh (Manager, Indexer, Dashboard)
- ModSecurity + OWASP Core Rule Set (CRS)
- DVWA (Damn Vulnerable Web Application)
- Kali Linux
- Ubuntu Server
- Apache Web Server

## Project Scope
- SOC lab setup using VirtualBox
- Centralized log collection and alerting using Wazuh
- Web application protection using ModSecurity WAF
- Attack simulation (SQL Injection, XSS, Brute Force)
- Monitoring and alert analysis via Wazuh Dashboard
